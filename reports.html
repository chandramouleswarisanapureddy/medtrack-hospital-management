Data Engineering Pipeline (ETL Architecture)

data_engineering/pipeline.py

1. Extract Phase

Ingests transactional records across Branch A, B, and C databases, appointment logs, and pharmacy registers.

2. Transform Phase

Standardizes ISO timestamps, expands date dimensions, computes doctor workload distributions and revenue KPIs.

3. Validate Phase

Enforces strict assertion checks: verifies non-negative stock levels and checks valid status enumerations.

4. Load Phase

Exports clean analytical data marts (fact_appointments.csv, dim_branch_performance.csv) and executive summaries.
